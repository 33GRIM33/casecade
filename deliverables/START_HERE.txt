ATTENTIONTWIN WELLNESS — PROJECT 2

1. Copy AttentionTwin-Wellness.apk to an Android 8+ phone. Open it and allow installation from that source if Android prompts. It is a debug-signed demonstration build.
2. Complete setup, or continue without notification access to explore Wellness. Allow notifications for background reminders.
3. Wellness opens with Study. Choose a one-minute focus and one-minute break for a quick demo.
4. Explore Wind down, Check-in and Reflect. Settings includes notification app roles.
5. No server or account is required for wellness. Background reminders are subject to Android battery restrictions.

OFFLINE BROWSER DEMO
Open offline-demo.html in a modern desktop browser. It includes all screens and local journal persistence. Android notification access and background reminders require the APK. Use the same browser and file path to preserve demo data.
